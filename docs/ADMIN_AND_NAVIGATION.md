# Parrot Rewards: offers administration

Open http://127.0.0.1:4200/admin/offers on this computer and sign in using the admin account supplied in chat. Customer accounts use the Android app; administrators use this web workspace.

Choose Manage offers to create an offer or edit an existing one. Configure its category, merchant, prices, conditions, availability and claim limits. Save as a draft until ready to publish. Keep unconfirmed examples labelled as sample offers. This workspace also provides categories, claims and reference lookup. Purchase records opens the separate receipts, merchant, people and review tools.

Customer navigation: Discover, My Claims, Updates and Account remain visible across signed-in screens. Back returns to the preceding screen; Forward reopens the screen just left using Back. Opening another destination starts a new navigation path. Account contains purchase receipts and purchase history.
